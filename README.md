# Ansh Cricket Trader — GitHub Pages

## Upload
1. Create a GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. In **Settings → Pages**, select the `main` branch and `/ (root)`.
4. Save and open the generated GitHub Pages URL.

## Important
Open `index.html` and replace:
`https://t.me/YOUR_CHANNEL`
with your real Telegram channel link.

The landing page is responsive and works on mobile and desktop.
